# Dashboard scripts

This directory contains automation scripts for profile assets.

## Regenerate profile dashboard locally

From repository root:

```bash
python -m pip install -r requirements.txt
python scripts/gen_dashboard.py
```

This command updates `/home/runner/work/maezgonz/maezgonz/profile_dashboard.png` from `/home/runner/work/maezgonz/maezgonz/metrics.json`.
